# mnemo-mcp (renamed)

**This distribution has been renamed to [`n24q02m-mnemo`](https://pypi.org/project/n24q02m-mnemo/).**

`mnemo-mcp` is now a transitional stub: installing it installs `n24q02m-mnemo` and keeps the
legacy `mnemo-mcp` command pointing at the same entry point, so existing
`uvx mnemo-mcp` and `pip install mnemo-mcp` setups keep working. Please switch to:

```bash
uvx n24q02m-mnemo
pip install n24q02m-mnemo
```

No further releases of `mnemo-mcp` are planned beyond this stub. Source and issues:
https://github.com/n24q02m/mnemo
